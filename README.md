# Tumbi Køkken
En lille kogebog til iPad, hvor et barn (ca. 5-9 år) og en voksen laver mad sammen, ét trin pr. skærm. Statisk PWA uden afhængigheder, ikke udgivet endnu.
Tests: `node test/koer-alle.js` i `D:\Claude\Kogebog`. E2E i WebKit er tung og kører kun gennem `tung-koersel.sh`.
Lokal server: `py -m http.server 8091 --bind 127.0.0.1 --directory D:/Claude/Kogebog`, og åbn http://127.0.0.1:8091/ (aldrig `file://`).
Start med `LÆS-MIG-FØRST.md`. Kommandoer og regler står i `CLAUDE.md`, og status i `STATUS.md`.
